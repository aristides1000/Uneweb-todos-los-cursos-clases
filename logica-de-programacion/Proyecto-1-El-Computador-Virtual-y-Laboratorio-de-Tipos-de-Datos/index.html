Construcción de Programas

Algoritmo vs Pseudocódigo vs Código

Un algoritmo es la serie de pasos lógicos finitos. El pseudocódigo es un borrador estructurado en lenguaje natural, y el código JS es la implementación ejecutable por el computador.

Capacidad de Abstracción y Fases

Abstraer es aislar los datos esenciales del problema. Las fases de resolución incluyen: Análisis del problema, Diseño del Algoritmo, Codificación, Pruebas y Depuración.

Calidad de los Programas

Se mide por su correctitud, eficiencia, legibilidad (buen nombrado de variables y comentarios) y mantenibilidad.

Tipos de Datos Elementales en JS

Number Primitivo

Numérico (Enteros y decimales)

Ej: 42, 3.1416. Acepta operaciones aritméticas.

String Primitivo

Cadena de Caracteres (Texto)

Ej: "Hola Mundo". Acepta concatenación y operadores de texto.

Boolean Primitivo

Lógico (Booleano)

Ej: true o false. Resultado de comparaciones y lógica.
